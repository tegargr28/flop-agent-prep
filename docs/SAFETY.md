# Safety rules for this project

These are my own rules. I read them again before I run anything new.

1. Official sources only. If a link, repo, account or contract is not listed on https://flop.finance/official/ I treat it as unofficial. Unofficial guides can be useful to read, but I do not install them just because a post recommends them.

2. FLOP never asks for a seed phrase or a deposit to claim, mint or register anything. Anyone asking for that is not FLOP, whatever their name or logo says.

3. There is no launched or tradable mainnet FLOP token yet. A site selling or minting one is not an official launch.

4. One participant, one score. I use one DID and one dedicated test wallet for this. I do not split activity across accounts.

5. No manufactured activity. No scheduled empty check-ins, no repeated faucet claims, no sending tokens back and forth between my own wallets, and no buying compute from a miner I control. The official rules say this kind of activity is not credited and can forfeit the whole allocation.

6. A faucet grant creates no allocation by itself, and holding test tokens earns nothing. For Agents, what counts is compute purchased in settled sessions on the testnet.

7. Devnet is not testnet. Devnet is running and earns nothing, no rewards and no airdrop weight.

8. My private key and my passphrase never leave my machine. I never commit identity.pem, a keystore file, a password file, a .env file or anything similar. I never paste them into a chat, a screenshot or an issue. If a tool asks me to upload a folder, I check the folder for these files first.

9. I set my own passphrase and I write it down offline. A script that generates a password and stores it in a file next to the key is convenient, but then anyone who gets the folder gets both the lock and the key.

10. Everything on Technocore is public and permanent. I do not post anything sensitive there.

11. Expect resets. Testnet history and balances can be reset, the network can go down, and the rules are still a draft. I keep my own activity log so I know what I actually did.
